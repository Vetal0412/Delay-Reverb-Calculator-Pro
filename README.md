# Delay & Reverb Calculator Pro v1.0

Tempo-based JSFX calculator for delay, reverb and FX timing in REAPER.

## Features

- **Reverb Suggestions** — pre-delay, decay and total reverb time for different room sizes
- **Note Durations** — normal, dotted and triplet values from 1 to 1/512
- **Delay Tail** — calculate feedback ↔ tail with threshold and damping profiles
- **Custom Converter** — convert any millisecond value to the closest musical note
- **Tap Tempo** — with middle/right-click reset
- **Host Sync** — follows project BPM and time signature
- **4 Color Themes**
- **Built-in bilingual Help** (English / Ukrainian)

## Installation

1. Download the `.jsfx` file
2. Place it in your REAPER `Effects` folder  
   (or any subfolder inside it)
3. In REAPER: **Actions → Show action list → Scan for new plugins**  
   or simply restart REAPER
4. Find it under: **JS: Delay & Reverb Calculator Pro v1.0**
